# Lenovo Dock Stations for GLPI

## О плагине

Плагин добавляет в GLPI отдельный тип актива **«Док-станции»** и автоматически
распознаёт док-станции Lenovo по данным USB-инвентаризации GLPI Agent.

Основные возможности:

- Определение названия, модели, производителя и серийного номера по USB VID/PID.
- Карточки док-станций со стандартными поиском, историей, документами
  и финансовой информацией GLPI.
- Связи док-станций с компьютерами и показатели на панели активов.
- Заполнение пользователя и местоположения по связанному компьютеру.
- Перенос распознанных док-станций из раздела «Устройства».
- Настраиваемый каталог моделей и правила обработки серийных номеров.
- Несколько производителей, VID и упорядоченных правил для моделей и PID.
- Импорт и экспорт настроек в JSON с предварительной проверкой.
- Предварительная проверка распознавания и переноса в интерфейсе плагина.

В поставку включены настройки только для Lenovo. Других производителей можно
добавить вручную, если агент передаёт необходимые USB VID/PID и серийные номера.
Поддержка сторонних производителей не гарантируется.

## Лицензия

Плагин распространяется по лицензии [MIT](LICENSE).

## Требования

- GLPI **12.0.x**.
- PHP **8.4** или новее с расширениями JSON, mbstring и SimpleXML.
- GLPI Agent с передачей USB-устройств в отчёте инвентаризации.
- Настроенный планировщик автоматических действий GLPI.

## Установка

1. Распакуйте установочный архив в каталог `plugins` вашей установки GLPI.
   Путь к файлу плагина должен иметь вид `plugins/itcoreinventory/setup.php`.
2. В GLPI откройте **Настройки → Плагины**, установите и активируйте плагин.
3. Откройте настройки плагина и проверьте каталог моделей.
4. Проверьте автоматическое действие **DockInventory**.

После установки раздел **«Док-станции»** доступен в меню **«Активы»**.

Для установки из исходного кода клонируйте репозиторий в каталог
`plugins/itcoreinventory`. Установка зависимостей Composer для работы плагина
не требуется.

## Настройка

Настройки доступны из списка плагинов GLPI:

- **Общие** - распознавание устройств и заполнение карточек.
- **Производители** - названия и USB VID.
- **Модели и PID** - соответствия USB PID, моделей и названий.
- **Правила обработки** - порядок и область преобразования серийных номеров.
- **Проверка** - предпросмотр результата распознавания устройства.
- **Импорт и экспорт** - перенос настроек через JSON.
- **История настроек** - загрузка предыдущей редакции в форму.
- **Перенос устройств** - проверка и перенос существующих карточек.

Минимальный [пример JSON-пресета](examples/lenovo-usb-c.json) содержит одну модель.
Импорт заменяет профиль производителя целиком; перед применением проверьте состав моделей.

## Участие в разработке

Изменения принимаются через Pull Request. Код оформляется по PHP-FIG PSR-12.

Перед отправкой изменений выполните:

```sh
composer install
composer lint
composer style
composer test
```

Плагин является независимым проектом и не является официальным продуктом Lenovo
или проекта GLPI.
